Streams cheat sheet

Reading a fetch body as it arrives, and turning bytes into text safely.

The reader loop

const reader = response.body.getReader();   // locks the stream to this reader
const decoder = new TextDecoder();           // ONE per stream
let text = '';
try {
  while (true) {
    const { done, value } = await reader.read();   // value: Uint8Array
    if (done) break;
    text += decoder.decode(value, { stream: true });
  }
  text += decoder.decode();                  // flush leftover bytes
} finally {
  reader.releaseLock();                      // or reader.cancel() to stop early
}

reader.read() outcomes

SituationResult
A chunk is availableresolves { value: chunk, done: false }
Stream closedresolves { value: undefined, done: true }
Stream erroredrejects with the error

Source: MDN — Using readable streams

Stopping a stream

CallEffect
reader.cancel()Discard the stream and any queued chunks. Use it when the consumer stops early.
reader.releaseLock()Detach this reader so another reader can attach. The stream keeps going.
AbortController on fetchAbort the whole request, e.g. a "Stop generating" button.

Rules

  • Chunks are cut at byte positions: mid-character, mid-line, mid-event.
  • One TextDecoder per stream, { stream: true } on every chunk, bare decode() at the end.[MDN]
  • A body can be consumed once: reader or .json()/.text(), not both.[javascript.info]
  • for await (const chunk of response.body) works too; the reader gives you explicit cancel().
