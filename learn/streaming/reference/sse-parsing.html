SSE parsing, layer by layer

An SSE parser is three layers stacked: bytes → text → lines → events. Each layer holds its incomplete part until more data arrives.

LayerIncomplete part it holdsLesson
Bytes → textA split multi-byte character (inside TextDecoder)1
Text → linesA line with no ending yet, or a trailing \r2
Lines → eventsFields seen since the last empty line (data buffer, event type)3

Text → lines

async function* readLines(stream) {
  const reader = stream.getReader();
  const decoder = new TextDecoder();
  let buffer = '';

  function* takeLines(final) {
    let start = 0;
    for (let i = 0; i < buffer.length; i++) {
      const ch = buffer[i];
      if (ch === '\n') {
        yield buffer.slice(start, i);
      } else if (ch === '\r') {
        if (i === buffer.length - 1 && !final) break; // maybe half of \r\n: wait
        yield buffer.slice(start, i);
        if (buffer[i + 1] === '\n') i++;                // \r\n is ONE ending
      } else continue;
      start = i + 1;
    }
    buffer = buffer.slice(start);                       // keep the unfinished tail
  }

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    buffer += decoder.decode(value, { stream: true });
    yield* takeLines(false);
  }
  buffer += decoder.decode();
  yield* takeLines(true);
  // leftover buffer = line with no ending → dropped
}

Line rules

RuleWhy
\r\n, \n, \r all end a lineSpec allows all three.[WHATWG]
Trailing \r waits for the next chunkIt may be half of a split \r\n. Guessing early creates a fake blank line.
Final \r at end of stream ends the lineNo more data can follow it.
Blank lines are yielded as ""A blank line dispatches an event.
Unterminated last line is dropped"Once the end of the file is reached, any pending data must be discarded."[WHATWG]

Lines → events

function* toEvents(lines) {
  let data = '', type = '', lastId = '';
  for (const line of lines) {
    if (line === '') {                                   // empty line: send
      if (data !== '') yield { event: type || 'message', data: data.slice(0, -1), id: lastId };
      data = ''; type = '';                              // lastId is NOT reset
      continue;
    }
    if (line.startsWith(':')) continue;                  // comment
    const colon = line.indexOf(':');                     // FIRST colon
    const field = colon === -1 ? line : line.slice(0, colon);
    let value = colon === -1 ? '' : line.slice(colon + 1);
    if (value.startsWith(' ')) value = value.slice(1);   // ONE space
    if (field === 'data') data += value + '\n';
    else if (field === 'event') type = value;
    else if (field === 'id') lastId = value;
    // anything else (retry, unknown): ignore
  }
  // no empty line at the end → last event not sent
}

Don't

  • chunk.split('\n') per chunk: lines are cut across chunks.
  • text.split('\n\n') for events: misses \r\n\r\n, and the two breaks may arrive in different chunks.
  • Strip all \r before splitting: breaks \r-only line endings.
